# Claude @-path

[English](README.md)

Невелике розширення VS Code: відправляє файли з Explorer у чат
[Claude Code](https://marketplace.visualstudio.com/items?itemName=anthropic.claude-code) як `@`-згадки
(наприклад `@Tasks/4_testing/89618/task.md`) або копіює `@`-шлях у буфер обміну.

Стане в пригоді, якщо перетягування з Explorer у панель Claude Code у вас не працює.

## Можливості

| Дія | Контекстне меню Explorer | Клавіша (фокус в Explorer) |
|---|---|---|
| Відправити файл у чат Claude Code як `@`-згадку | **Claude: відправити в Claude Code** | `Alt+K` |
| Скопіювати `@`-шлях у буфер обміну | **Claude: скопіювати @-шлях** | `Alt+Shift+K` |

- Обидві дії є також у контекстному меню вкладки редактора.
- Працює мультивибір: виділіть кілька файлів через `Ctrl+клік`, і вони відправляться або скопіюються разом.
- Шлях береться відносно кореня workspace, з прямими слешами. До каталогу додається `/` у кінці, а шлях із
  пробілами береться в лапки.
- Каталоги та файли, які не відкриваються як текст (зображення тощо), напряму вставити не можна. Розширення копіює
  їхні `@`-шляхи в буфер і ставить курсор у поле чату, тож лишається натиснути `Ctrl+V`.
- `Alt+K` у текстовому редакторі лишається за вбудованою командою Claude Code **Insert @-Mention Reference**.
  Це розширення займає `Alt+K` лише тоді, коли фокус в Explorer.

## Як це працює

Вбудована команда Claude Code `claude-vscode.insertAtMention` працює лише з активним редактором. Розширення
відкриває вибраний файл у вкладці попереднього перегляду, без виділення, щоб у згадку не потрапив діапазон рядків,
і викликає цю команду.

Клавіша не передає команді вибране в Explorer. Щоб його отримати, розширення виконує команду VS Code
`copyFilePath`, читає буфер обміну і потім повертає туди попередній вміст.

## Вимоги

- VS Code 1.80 або новіший.
- Розширення Claude Code (`anthropic.claude-code`) — потрібне для **відправити**. **Скопіювати** працює і без нього.

## Встановлення на іншому компʼютері

### Варіант 1: з релізу (рекомендовано)

1. Завантажте `claude-path.vsix` зі сторінки [Releases](https://github.com/dsvsergey/claude-path-ext/releases).
2. Встановіть одним зі способів:
   - з термінала:
     ```
     code --install-extension claude-path.vsix
     ```
   - з VS Code: відкрийте панель Extensions (`Ctrl+Shift+X`), натисніть **⋯** угорі, виберіть
     **Install from VSIX…** і вкажіть файл.
3. Перезавантажте вікно: `Ctrl+Shift+P` → **Developer: Reload Window**.

### Варіант 2: зібрати з вихідного коду

Для збирання потрібен лише Python 3, без пакетів і без Node.js.

```
git clone https://github.com/dsvsergey/claude-path-ext.git
cd claude-path-ext
python build_vsix.py
code --install-extension claude-path.vsix --force
```

Потім перезавантажте вікно.

Якщо в терміналі немає команди `code`, відкрийте VS Code і виконайте `Ctrl+Shift+P` →
**Shell Command: Install 'code' command in PATH**. У Windows вона зазвичай уже є в `PATH` після встановлення.

## Оновлення

Встановіть новий `.vsix` з `--force` і перезавантажте вікно. Змінюючи код, збільшуйте `version` у `package.json`.

## Видалення

```
code --uninstall-extension local.claude-path
```

Або видаліть у панелі Extensions.

## Файли

| Файл | Призначення |
|---|---|
| `package.json` | Маніфест розширення: команди, меню, клавіші |
| `extension.js` | Реалізація команд |
| `build_vsix.py` | Пакує `package.json` і `extension.js` у `claude-path.vsix` без `vsce` |

## Якщо не працює

- **Немає пунктів меню або клавіша нічого не робить:** перезавантажте вікно і перевірте, що розширення увімкнене
  в панелі Extensions.
- **`Alt+K` не спрацьовує в Explorer:** клавішу могло перехопити інше розширення. Відкрийте `Ctrl+K Ctrl+S`,
  знайдіть `claudePath` і призначте свою клавішу.
- **У чат нічого не вставляється:** перевірте, що панель Claude Code відкрита. У режимі термінала
  (`claudeCode.useTerminal`) користуйтеся **скопіювати** і вставляйте шлях вручну.
